                        Als App aufs Handy

                        Legen Sie diese Seite als Symbol auf Ihren Startbildschirm – dann ist Ihr Fall immer nur einen Tipp entfernt.

                        iPhone: unten auf Teilen (Quadrat mit Pfeil) tippen, dann „Zum Home-Bildschirm“. Öffnen Sie danach einmal Ihren persönlichen Link (unten) im neuen Symbol.

                        Android: oben rechts auf ⋮ tippen, dann „Zum Startbildschirm hinzufügen“ oder „App installieren“.
